# 강원대 합격 주파수 📡

**102.7 MHz**에 맞추면 기분 좋은 강원대 합격 기운을 수신하는 패러디 웹사이트.

- HTML/CSS/JavaScript 단일 파일. 설치·빌드·서버 불필요
- 모바일 반응형 FM 라디오, 주파수 슬라이더, 자동 튜닝, 파형 애니메이션
- Web Audio 합성 알림음(선택), 4초 수신 이벤트, 축하 컨페티
- 이름을 넣어 합격 기원 카드 PNG 저장, 웹 공유/링크 복사
- 네트워크로 개인정보 전송하지 않음, 실제 입학 결과와 무관

`index.html`을 브라우저에서 열면 바로 동작합니다.

> **주의:** 강원대학교와 무관한 비공식 응원용 프로젝트입니다. 합격 여부와 합격 확률을 나타내지 않습니다.
